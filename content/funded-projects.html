Research and Applications Projects 

  • 2020 - 2023 :: MoSoRe - Project aimed at bringing resiliency in systems for mobility

  • 2021 - 2023 :: AIPLAN4EU - Project aimed at making automated planning systems and languages available and accessible for the mass. Github. Demo at ICAPS-22

  • 2017 - 2019 :: MAIS - R&D project aimed at the automatisation of a galvanic plant. I have been participating to this project during my period at the Fondazione Bruno Kessler. We were focused on the problem of planning and controlling the movements of a set of hoists (an extension of the famous Hoist Scheduling Problem) tasked to fulfill the cyclic production of the galvanic plant; we tackled the arising optimisation task using heuristic search over an action-based temporal model. Parts of our formal model are described in the AAAI-19 paper.

  • 2015 - 2017 :: Australian Research Council Project (ARC) - This was a basic research project aimed at investigating new models and methods for Robust AI Planning for Hybrid Systems. This project has led to a number of publications (IJCAI, ICAPS, ECAI) and to the development of two planning systems, ENHSP and SPRINGROLL.

  • 2009 - 2012 :: Sistemi e Tecnologie per l'EsPlorazione Spaziale (STEPS) - R&D project aimed at investigating methodologies for the next Space Missions. The project involved a number of Industrial and Academic organizations and was leaded by Thales Alenia Space.
